year: "1987"
title: "Vaški vodovod in hidrantno omrežje"
description: >-
  Začela se je gradnja vaškega vodovoda in urejanje hidrantnega omrežja. Razvoj oskrbe kraja z
  vodo se je tako povezal tudi s potrebami požarne varnosti. Hidrantno omrežje je pomenilo
  pomembno dopolnitev gasilske opreme, saj so hidranti omogočali dostop do vode za gašenje.
