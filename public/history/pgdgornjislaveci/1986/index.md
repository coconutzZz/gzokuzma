title: "Novo vodstvo in obnova gasilskega doma"
description: >-
  Društvo je 9. februarja 1986 organiziralo borovo gostüvanje. Istega leta je bila med gasilskim domom
  in skladiščem prizidana garaža za orodno vozilo TAM, nabavljeno leta 1982. Leta 1988 predsedniško
  funkcijo prevzame Drago Lovenjak. Slavko Kous postane tajnik društva. Novo vodstvo je v naslednjih
  letih sodelovalo pri obnovi in dograditvi gasilskega doma. Z obnovo in dograditvijo gasilskega doma
  so začeli leta 1989. Dela so zajela celovito prenovo in izgradnjo stolpa. Prenovljeni in dograjeni
  gasilski dom je bil predan svojemu namenu leta 1993. Pri gradnji so se posebej izkazali Alojz Kovač,
  Rudi Rogan, Viljem Prem, Drago Lovenjak in Alojz Krpič. Naloge strojnika je istega leta prevzel
  Slavko Krpič.
